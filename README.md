# Currency Converter

# Spring Boot application for calculating currency conversion
    Convert USD to other world currencies using real-time exchange rates.

## Used techologies:

        - Java SE
        - Spring Boot
        

## App logic

    Based on the entered USD amount, the app calculates and returns the equivalent amount in other currencies.

*****

## Status: Early Development
    At the moment, the project is in its initial version. The app currently performs currency conversions using fixed, hardcoded exchange rates. I plan to integrate an API soon so that the app can use real-time exchange rates.

    I also plan to improve the app in the future by allowing users to enter amounts in different currencies, not just USD.
